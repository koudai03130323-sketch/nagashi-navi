# 日報の写真を表にする指示文（運転手が自分のAIに送る）

アプリの「日報の写真から読み取る」画面に、この指示文のコピーボタンを置く。運転手は ChatGPT や Claude のアプリで新しいチャットを始め、最初にこれを1回だけ貼って送る。「準備できました」と返ってきたら、あとは日報の写真を送るだけで、流しナビに貼れるCSVが返ってくる。

`public/index.html` の `OCR_PROMPT` と同じ内容にしておくこと。

AIはこの表をどこにも送らない。運営者のスプレッドシートに届くのは、運転手がアプリに取り込み、アプリの「記録の提供」に同意している場合だけ（町名までに丸めて、アプリから送る）。

---

これから、タクシーの乗務員日報の写真を送ります。この会話のあいだ、写真が届くたびに、乗車の記録を「流しナビ」に貼れるCSVにしてください。

返し方:
- CSVだけを、1つのコードブロックに入れて返す。1行目はいつも次の見出しにする。
日付,乗車,降車,乗車地,降車地,営業km
- コードブロックの外には「全部で○件・空欄にした所」を1行だけ書く。あいさつや説明は書かない。
- 何日分の写真が届いても、1つのCSVにまとめる。

決まり:
- 日付は日報上部の「出庫日時」の年月日を、2025/02/21 の形で全行に入れる。
- 1乗車を1行にする。「出」（出庫）の行と「入」（入庫）の行は入れない。
- 乗車地と降車地の両方が空欄の行（キャンセル）は入れない。
- 乗車・降車は 9:02 の形。
- 乗車地・降車地は日報の表記どおり（例：宮前区有馬2、たまプラーザ北口）。
- 営業kmは数字だけ（例：3.3）。
- 料金・人数・支払い・備考・手書きのメモは入れない。
- 用紙が傾いていたら、No.の列と時刻・地名・kmの行の対応を、件数を数えて合わせる。
- 読めない字は推測で埋めず、その欄を空にする。
- 写真が2枚（1/2・2/2ページ）あれば、続けて1つの表にする。

この文を読んだら「準備できました。日報の写真を送ってください。」とだけ返してください。
