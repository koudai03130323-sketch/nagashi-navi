# 日報の写真をスプレッドシートにする（ChatGPT／Claude で使える）

日報の写真をAIに読ませて、スプレッドシート（Googleスプレッドシート・Excel）に貼れる表にする方法です。ChatGPT（チャッピー）でも Claude でも同じ手順で使えます。AIの無料プランでも、数枚ずつなら使えます。

## 使い方

1. ChatGPT のアプリ（または Claude のアプリ）を開き、新しいチャットを始める。
2. 日報の写真を添付する（1日分。2ページあるときは2枚とも）。
3. 下の「コピペ用の指示文」を丸ごと貼り付けて送る。
4. 返ってきた表の右上にある「コピー」を押す（表が出ないときは、返事の文字を長押しして全部コピー）。
5. スプレッドシートを開き、空いている行の一番左（A列）を選んで貼り付ける。
   - 1枚目の写真のときだけ、見出しの行も一緒に貼る。2枚目からは見出しの行を消してから貼る。
6. 写真と見比べて、時刻や地名が合っているか、ざっと確かめる。空欄になっているところは、AIが読めなかったところなので、写真を見て手で直す。

たまった表は、スプレッドシートの「ファイル → ダウンロード → CSV」で保存すると、流しナビにそのまま読み込めます。

## コピペ用の指示文

```
この写真はタクシーの乗務員日報です。乗車の記録を表にしてください。
説明やあいさつは書かず、表だけを返してください。

列は次の6つ、この順番です。
日付 | 乗車 | 降車 | 乗車地 | 降車地 | 営業km

決まり:
- 日付は日報上部の「出庫日時」の年月日を 2025/02/21 の形で、全部の行に入れる。
- 1乗車を1行にする。「出」（出庫）と「入」（入庫）の行は入れない。
- 乗車地と降車地が両方とも空欄の行（キャンセル）は入れない。
- 乗車・降車の時刻は 9:02 の形。
- 乗車地・降車地は日報に書いてあるとおり（例：宮前区有馬2、たまプラーザ北口）。
- 営業kmは数字だけ（例：3.3）。
- 料金・人数・支払い・備考・手書きのメモは入れない。
- 用紙が斜めに写っていたら、行がずれないように、No.の列と時刻・地名・kmを件数で数えて対応させる。
- 読めない字は推測で埋めず、その欄を空にする。
- 写真が2枚（1/2・2/2ページ）あるときは、続けて1つの表にする。
- 最後に「全部で何件か」と「空欄にした箇所」を1行で書く。
```

## うまくいかないとき
- **表ではなく文章で返ってきた：** 「表だけで返して」ともう一度送る。
- **貼り付けたら1つのセルに全部入った：** 「タブ区切りのテキストで返して」と頼んで、もう一度コピーして貼る。
- **行がずれている気がする：** 「No.○の行の時刻と乗車地をもう一度確かめて」と、行番号を指定して聞き直す。
- **写真が暗い・ぼやけている：** 明るい場所で、用紙全体が入るように真上から撮り直す。

## 気をつけること
- 日報は会社の記録です。AIに写真を送ってよいか、会社のルールを確認してから使ってください。
- 写真にお客さんの情報が写っている場合は、送る前にその部分を隠してください。
