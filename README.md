# 流しナビ

タクシーの乗務記録から、いま・どこへ行けば客がつきやすいか、降ろしたあとどこへ向かうかを出すWebアプリです。無料の範囲（GitHub Pages＋Googleスプレッドシート）で動かします。

## Claude Code での始め方
1. このフォルダで Claude Code を開く。
2. 最初に「CLAUDE.md を読んで、まだのことの1番から進めて」と頼む。

## 手元で動かす
```
cd public
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開き、「サンプルで試してみる」か、自分のExcel（.xlsx）／CSVを読み込む。

## 公開（GitHub Pages）
1. GitHub にこのリポジトリを置く（ブランチ名は `main`）。
2. Settings → Pages → Source を「GitHub Actions」にする（初回だけ）。
3. `main` に push すると、`.github/workflows/pages.yml` が `public/` の中身をそのまま公開する。

公開先は `https://<ユーザー名>.github.io/<リポジトリ名>/`。アプリの中のパスはすべて相対なので、この形のURLでそのまま動く。
（「ブランチから公開」は `/` か `/docs` しか選べず `public/` を指定できないので、Actions を使う。）

## 記録の受け口（Google Apps Script）
先に、みんなの記録が書き込まれる空のスプレッドシートを作る。
1. https://sheets.new を開く（新しい空のスプレッドシートができる）。名前は「流しナビ 記録の受け口」など。**誰とも共有しない。**
2. 見出しは入れなくてよい（最初の記録が届いたときに、`records` というシートと見出しが自動でできる）。
3. そのスプレッドシートで 拡張機能 → Apps Script を開く。ここから下の手順に続く。

1. `apps-script/Code.gs` の先頭の手順どおりに設置する。
2. 出てきた「ウェブアプリのURL」を `public/config.js` の `collectUrl` に入れる。あわせて `operator`（運営者の名前）と `contact`（連絡先）も入れる。この2つは同意画面にそのまま出る。
3. 公開したアプリで自分の記録を1件だけ入れ、記録の画面の「記録の提供」から同意して、シートに行が入るか確かめる。

`collectUrl` が空のあいだは、「記録の提供」はアプリに出ず、どこにも何も送らない。

送られるのは、日付・曜日・乗車と降車の時刻・乗車地と降車地（区・市と町名まで、または駅名）・営業km・端末ごとのでたらめな番号（送信ID）。地図の辞書にない場所の名前は空にして送る。

運転手から「送った記録を消してほしい」と言われたら、送信IDを聞き、シートでその送信IDの行を消す。

## みんなのデータをアプリに出す
集まった記録から、個人が特定できない集計だけを作ってアプリに見せる。
1. 受け口のスプレッドシートで `records` シートを開き、ファイル → ダウンロード → カンマ区切り形式（.csv）。
2. `python3 tools/build_minna.py ダウンロードしたファイル.csv`
3. できた `public/minna.json` を push する。アプリの「いま」「降ろしたあと」に「みんなのデータでは」が出る。

回数が5回未満、または運転手が3人未満のところは出ない。運転手が全体で3人に満たないあいだは、何も出ない。
自分（運営者）の記録も入れたいときは、自分のスマホのアプリで記録を読み込み、「記録の提供」に同意して送る。

## ホーム画面に追加（PWA）
公開したURLをスマホで開き、iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome の「︙」→「ホーム画面に追加」。一度開けば、地図と辞書が端末にたまり、電波のないところでも開ける。
アプリを直して push したあとは、利用者が次に開いたときに裏で新しいものを取り、その次に開いたときから新しくなる。

## 運営者として気をつけること
- 集めるのは、同意した人の、町名までに丸めた記録だけにする。
- 乗車地・降車地と時刻は、お客さんの自宅などが分かりうる情報。日報は会社の記録でもある。本格的に集める前に、個人情報保護法や各社の取り決めについて専門家に確認する。
- 集めたシートは誰とも共有しない。共有するなら、同意画面にそのことを書く。
